Everything the podium needs

Built around how a real host stand runs a shift — not a generic reservation system bolted on afterward.

Live table map

A visual floor plan that shows which tables are booked, seated, or free — with a time scrubber to preview any slot ahead.

Auto-generated checklist

Every booking generates its own prep and seating events automatically, grouped by time, so nothing gets missed during a rush.

Real-time multi-device sync

Check something off at the podium and it updates instantly on the manager's tablet — no refreshing, no double-checking.

Web push notifications

Get a push notification a few minutes ahead of the next wipe or seat, so hosts stay a step ahead instead of reacting.

CSV import

Drop in a RunSheet export and bookings load straight onto the board — no manual re-typing at the start of shift.

PIN-protected, zero setup per shift

One shared login for the host stand, a separate PIN for admin settings — nothing to configure device by device.

How it works

1

Set up your venue

Your hours, table layout, and checklist events are configured once, specific to how your floor actually runs.

2

Log in at the stand

Hosts open the board on any device — phone, tablet, or the host stand screen — with a shared PIN.

3

Run the shift in sync

Bookings, the table map, and the checklist stay in lockstep across every device, all shift long.
